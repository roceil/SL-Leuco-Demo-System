# Leuco Sapphire 藍白航運訂票系統 - 設計分析報告

## 📋 執行摘要

本報告針對藍白航運（Leuco Sapphire）訂票系統進行全面的使用者介面與使用者體驗分析，涵蓋登入頁面、訂票系統、訂單查詢、報表總覽及帳號設定等核心功能頁面。

**分析日期：** 2026-01-10
**系統網址：** https://dashboard.leucosapphire.com
**測試帳號：** trip_services_test@tripackage.com.tw

2. 添加即時表單驗證與錯誤提示
3. 加入「忘記密碼」連結

5. 增加 focus 狀態視覺回饋

---

### 訂票頁面（訂位作業）

**優點：**
✅ 去程/回程用不同顏色區分（藍色/黃色）
✅ 票種選擇清晰，顯示原價與折扣價
✅ 實時顯示總金額

**缺點：**
❌ OCR 警告訊息位置過於突出，干擾主要操作流程
❌ 表單過長，需要大量滾動
❌ 去程/回程顏色對比不足（淡藍/淡黃背景對比度低）
❌ 日期選擇器顯示為「0/0/0」不直觀
❌ 必填欄位標記（*）顏色不夠明顯
❌ 缺少表單進度指示

**改善建議：**

1. **採用步驟式表單設計**
   ```
   [1.選擇航程] → [2.乘客資訊] → [3.票種數量] → [4.確認]
   ```

2. **改善去程/回程視覺區分**
   - 去程：深藍色標題 (#1976d2) + 白色背景 + 藍色左側邊框
   - 回程：橙色標題 (#f57c00) + 白色背景 + 橙色左側邊框

3. **移動 OCR 警告**
   - 將警告移至頂部通知欄
   - 使用可關閉的淡化警告樣式

4. **改善日期選擇器**
   - 使用日曆彈窗介面
   - 預設顯示今天的日期

5. **增強必填欄位標示**
   - 使用紅色 * 號
   - 在欄位名稱後方加上 *(必填)

6. **加入票種說明工具提示**
   - 滑鼠懸停顯示票種詳細說明

## 🚨 設計系統問題彙整

### 一致性問題

| 問題類型 | 具體表現 | 影響程度 |
|---------|---------|---------|
| 按鈕樣式不一致 | 有些用實心、有些用外框 | 高 |
| 顏色使用不一致 | 相同功能用不同顏色 | 中 |
| 間距不統一 | 不同頁面的元素間距差異大 | 中 |
| 字體大小不統一 | 標題、正文字體大小缺少層次 | 低 |

### 無障礙問題

| 問題類型 | 具體表現 | WCAG 標準 |
|---------|---------|----------|
| 顏色對比度 | 淺藍背景上的白色文字 | AA 級不合格 |
| 缺少鍵盤導航 | 無法用 Tab 鍵順暢導航 | AAA 級不合格 |
| 缺少 ARIA 標籤 | 螢幕閱讀器難以理解 | AA 級不合格 |
| 缺少焦點指示 | 鍵盤焦點不明顯 | AA 級不合格 |

### 響應式設計問題

| 裝置類型 | 主要問題 | 優先級 |
|---------|---------|--------|
| 手機 (< 768px) | 側邊欄遮擋內容 | 高 |
| 平板 (768-1024px) | 表格橫向溢出 | 中 |
| 小筆電 (1024-1366px) | 內容過於擁擠 | 低 |

## ♿ 無障礙改善建議

### 1. 鍵盤導航
```html
<!-- 所有互動元素都應該可以用 Tab 鍵導航 -->
<button tabindex="0">登入</button>

<!-- 跳過導航連結 -->
<a href="#main-content" class="skip-link">跳到主要內容</a>
```

### 2. ARIA 標籤
```html
<!-- 表單標籤 -->
<label for="username">帳號</label>
<input id="username" aria-required="true" aria-describedby="username-help">
<span id="username-help">請輸入您的電子郵件或手機號碼</span>

<!-- 錯誤訊息 -->
<input aria-invalid="true" aria-describedby="username-error">
<span id="username-error" role="alert">帳號格式不正確</span>
```

### 3. 顏色對比度
```
確保文字與背景的對比度至少達到：
- 正常文字：4.5:1 (AA 級)
- 大標題：3:1 (AA 級)
- 理想目標：7:1 (AAA 級)
```

## 🔧 技術建議

### 1. 前端框架
- **建議使用：** React + TypeScript 或 Vue 3
- **UI 元件庫：** Material-UI、Ant Design 或 Element Plus
- **狀態管理：** Redux、Pinia 或 Zustand
- **表單驗證：** Formik + Yup 或 VeeValidate

### 2. 響應式框架
- **CSS 框架：** Tailwind CSS 或 Bootstrap 5
- **網格系統：** CSS Grid + Flexbox

### 3. 無障礙工具
- **測試工具：** axe DevTools、WAVE
- **螢幕閱讀器測試：** NVDA、JAWS

### 4. 效能優化
- **圖片優化：** WebP 格式、懶載入
- **程式碼分割：** 路由級別的程式碼分割
- **快取策略：** Service Worker、HTTP 快取

## 📝 結論

藍白航運訂票系統在功能上已經相當完整，但在視覺設計、使用者體驗和無障礙方面仍有改善空間。主要問題包括：

1. **設計系統缺乏一致性** - 需要建立統一的設計規範
2. **表單流程過於複雜** - 需要簡化操作步驟
3. **響應式設計不完善** - 需要優化手機端體驗
4. **無障礙支援不足** - 需要加強鍵盤導航和螢幕閱讀器支援

透過本報告提供的改善建議，可以有效提升系統的整體使用者體驗，降低操作難度，提高訂票效率。
